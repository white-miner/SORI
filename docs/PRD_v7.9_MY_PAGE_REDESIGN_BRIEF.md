## 1. 제품 문장 (초안 · 잠금 후보)

소리는 소셜 앱이 아니다.  
마이페이지는 **원장의 샵 OS 홈**(운영·자산·경영·에이전트)이고,  
공개 프로필(손님·동료가 보는 면)은 그 **바깥 레이어**다.  
둘을 한 탭바에 억지로 섞지 않는다 — **면(surface)을 나누거나, 모드로 나눈다.**

## 2. 현재 코드 현실 (입구·통로·출구)

| 칸 | 위치 |
|----|------|
| 입구 | GNB 마이 탭 → `MyPage` → 원장 `DirectorMyPageView` / 고객 `CustomerMyPageView` |
| 통로 | `TabController(length: 6)` · 스토어 프로필·세미나·서포터 헤더 refresh |
| 출구(원장) | sticky 탭: **Home · 경영 · Shop · Asset · Seminar · AI** + 히어로 커버 |
| 경영 | `DirectorBizTabBody` → `/app/biz-dashboard` (ZONE 1~5) |
| 레거시 | Feed 탭 UI는 deprecated 보관(삭제 아님) |

**통증 (Cursor 관찰)**  
1. Home/Shop/Seminar = **공개 브랜드** 성격, 경영/Asset/AI = **사장 전용** → 한 줄 탭에 공존.  
2. Home 탭에 공지·AI 리포트·세미나 입구가 **분산**.  
3. 고객 마이와 원장 마이의 **IA 대칭이 없음**(의도는 다를 수 있음 — 명시 필요).  
4. v7.6이 “6탭 전면 BI 교체 기각”이므로, 개편은 **교체가 아니라 재배치·면 분리**여야 함.

## 3. Cursor 제안 IA (통합 전 후보 3안)

### 안 A — **이중 면 (추천 기울기)**

```
마이
 ├─ [프로필 면]  손님이 보는 샵 카드 · 스토리/B/A 허브 · 세미나 쇼케이스
 └─ [사장 책상]  경영 · Asset · AI · 설정 · (후) 컨설팅/에이전트
```

- 상단에 **면 스위처** (프로필 | 운영) 또는 세그먼트 컨트롤.  
- 기존 6탭 **삭제하지 않음** — 면 안으로 **이동·deprecated 라벨**.  
- 경영 라우트·대시보드 **유지**.

### 안 B — **역할 고정 탭 축소**

```
마이 탭 4개: 요약 · 경영 · 샵 · 더보기
  더보기 = Asset / Seminar / AI / 설정 (리스트)
```

- 탭 수 감소로 인지 부하↓.  
- Expand: 새 셸 + 구 탭 body 재사용.

### 안 C — **Instagram 유지 + 경영만 격상** (최소 개편)

- 6탭 라벨·순서만 정리 (예: 경영을 2번째 고정 — 이미 그럼).  
- Home 밀도만 낮추고 CTA를 경영·AI로 모음.  
- “대규모”에는 미달 — Perplexity/Claude가 **기각 근거**를 대면 폐기.
