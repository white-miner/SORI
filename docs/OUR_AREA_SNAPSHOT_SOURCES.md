## 데이터 source

우선순위대로 확인한 뒤, 좌표가 WGS84로 확인된 영업 중 뷰티 업소만 담았다.

| 우선 | source | 사용 |
|---|---|---|
| 1 | 소상공인시장진흥공단 상가(상권)정보 | `네일;설렘` sourceId `MA0101202307A0000768`, 업종 소분류 네일숍, 성건동 |
| 2 | 지자체 미용업 인허가 목록(영업) | `서라벌미용실`, `터치by현정`, `쏘쏘 스킨&바디`, `장은미 헤어샵` |
| — | OSM Overpass | 성건동 1km는 0건이라 실샵 스냅샷의 주 source로 쓰지 않음 |
| — | 행정안전부 전국미용업소표준데이터 CSV | 다운로드 타임아웃. EPSG:5174라 변환 전에는 반경 필터에 쓰지 않음 |

WGS84 좌표는 도로명 주소를 Nominatim으로 조회했다. 금성로 번지만으로 황남동/사정동에 붙은 점은 좌표계 오류로 보고 넣지 않았다.

## 좌표계 · 라이선스

| 항목 | 값 |
|---|---|
| 저장 좌표계 | WGS84 latitude / longitude |
| 쓰지 않는 좌표 | EPSG:5174 Bessel TM 원값 |
| 기준일 | 지역 JSON `sourceDate` (추측 금지) |
| 라이선스 | 공공 상가정보·인허가 목록 + Nominatim geocode(ODbL) |
| 금지 | 개별 업체 매출, 전화번호 확대, runtime client API key, 실시간 crawler |

앱 표시는 기존과 같다: `로컬 스냅샷 · 기준일 YYYY-MM-DD`.
