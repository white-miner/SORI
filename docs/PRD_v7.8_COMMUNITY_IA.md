## 0. 제품 정체성 (한 줄)

소리는 **소셜 앱이 아니다.**  
1인 샵이 매일 쓰는 **유틸리티 · 매니저 · 컨설팅 · 에이전트**가 중심이고,  
커뮤니티는 **통로를 닫지 않는** 공유·소식·멘토 레이어다.

| 중심 (우선) | 통로 (유지·가볍게) |
|-------------|-------------------|
| 차트 · 방문 · 타이머 · 촬영 | B/A 게시 |
| 경영 숫자 · 주변 상권 | 세미나·팁·리뷰 |
| (후) 컨설팅 · 에이전트 | 멘토 요청/지원 |

**지금 집중:** 커뮤니티 IA 완성 + 마이「경영」완성.  
**나중:** 마이페이지 대규모 개편 (본 문서 비범위).

## 2. 커뮤니티 3탭 IA (잠금)

화면 SSOT: `lib/views/unified_home_feed_page.dart`  
탭 라벨: **추천 · 탐색 · 우리 지역** (이름 유지).

### 2.1 추천

- **전국** 게시물이 매일 쌓여 보임.  
- 게시물은 **카테고리**를 가진다.  
- 목적: “오늘 업계에 뭐가 올라왔나” 한눈에.

**카테고리(초안 · PO 확정 필요)**

| id | 표시 | 예시 |
|----|------|------|
| `ba_case` | 전후(B/A) | 케이스 공유 |
| `seminar` | 세미나 | 일정·후기 |
| `tip_device` | 기기 리뷰 | 장비 |
| `tip_product` | 제품 리뷰 | 재료·코스메틱 |
| `news` | 소식 | 업계 단신 |
| `mentor_ask` | 멘토 요청 | 질문 |
| `mentor_offer` | 멘토 지원 | 답/제안 |

등록 UX: **빠르게** (짧 폼 · 사진 1~N · 카테고리 칩 필수).

### 2.2 탐색

- **카테고리별**로 모아보기 (칩 또는 섹션).  
- **검색** 가능 (제목·본문·해시·샵명 — 구현 페이즈에서 범위 확정).  
- 추천과 소스 동일, **정렬·필터만** 다름.

### 2.3 우리 지역 ⭐

세로 구성 (위→아래):

```
┌─────────────────────────────┐
│  지도 4:3                    │  ← 내 위치 또는 내 주소 중심
│  (공공 등록 샵 핀)            │
├─────────────────────────────┤
│ [전체][피부][네일][미용]…   │  ← 칩 · 지도 바로 아래 · 터치 쉽게
├─────────────────────────────┤
│  우리 지역 게시물 피드         │  ← 프로필 주소 기준 · 전국 아님
└─────────────────────────────┘
```

#### 지도

| 규칙 | 내용 |
|------|------|
| 중심 | ① 현재 위치(허용 시) ② 없으면 프로필/샵 **주소** ③ 둘 다 없으면 주소 입력 유도 |
| 범위 | **반경 km** (행정동 경계 아님 — 원장·고객 공통 UX). 기본 제안: 0.5 / 1 / 2 km 칩 |
| 비율 | **가로:세로 = 4:3** |
| 핀 데이터 | 소진공 상가정보 등 **공공 등록 업소** (소리 가입 샵만이 아님) |
| 칩 | `전체` · `피부샵` · `네일샵` · `미용실` · `바버샵` · `타투샵` · `반영구화장샵` |
| 탭 핀 | 상호 · 업종 · 거리(m) · (후) 상권 집계 지표 — **점포 실명+추정매출 결합 금지** |
| 사용자 | **원장·고객 모두** — “어디 mid 뭐가 있는지” 확인·방문·전략 |

#### 지역 피드 (지도 아래)

| | 추천 | 우리 지역 |
|--|------|-----------|
| 범위 | **전국** | **내 위치/주소 기준 반경 km** |
| 목적 | 업계 전체 흐름 | **동네 사람들끼리** 소통 |
| 콘텐츠 | 동일 카테고리 체계 | 동일 · 필터만 지역 |

기존 부스트 인터리브는 **지역 피드 구간**에서만 유지할지, 맵 도입 후 슬롯 정책을 재검토 (Phase에서 결정).
