# 우리지역 샵 카드 복구

## 동작
- 도로명주소와 원본 층수를 합쳐 표시한다. 원본 건물명 등은 응답에 보존한다.
- 거리 칩은 기기 위치를 얻은 경우에만 표시한다. 검색 반경과 목록 정렬은 기존 검색 중심을 유지한다.
- 인허가 조회는 샵 선택 시 실행한다. 상호(지점명 포함), 시도·시군구, 도로명과 건물번호가 일치해야 한다.
- 후보들의 영업상태·인허가일이 충돌하거나 결과 페이지가 잘려 있으면 상태를 확정하지 않는다.
- 정상 영업에만 파란 상태 칩과 초록 연차 칩을 표시한다. 연차는 올해 − 인허가 연도 + 1이다.
- 성공/미매칭을 앱 세션 메모리에 24시간 저장한다. 앱 재시작 시 캐시는 초기화된다. 일시 오류는 다음 선택 시 재시도한다.
- 키는 Edge Secret `MOIS_BEAUTY_LICENSE_SERVICE_KEY`에서만 읽는다.

## 승인 후 배포 및 실제 검증
1. PR을 머지하고 앱 빌드를 확인한다.
2. 기존 Supabase 프로젝트의 `get-shop-market`만 재배포한다. 스키마 변경은 없다.
3. 피어나스킨엔바디를 선택하여 실제 주소·층수와 인허가 응답을 확인한다. 예시 화면의 2019년은 테스트 데이터이며 실제 인허가일을 뜻하지 않는다.
4. GPS 허용/거부, 검색 주소 변경, 정상/미매칭/조회 실패와 재시도를 확인한다.
5. API 후보가 모호하면 두 상태 칩을 숨기는 것이 정상이다. 이를 폐업으로 표시하지 않는다.

## 롤백
PR을 revert하고 이전 `get-shop-market`을 다시 배포한다. 새 응답 필드는 추가형이고, 기존 앱/API와 호환된다.

## 후속 할 일
- 상권분석 화면에 「내 샵 위치」 기능을 별도 구현한다.
- 앱 재시작을 넘어서는 영속 캐시가 필요하면 저장소·만료·갱신 정책을 별도 설계한다.
