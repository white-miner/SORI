# SORI 시각 디자인 기준

**효력:** 2026-09-24 · 제품 소유자 지시. 모든 새 UI와 수정 UI에 적용한다. 기존 `docs/SORI_DESIGN_LAWS.md`와 충돌하면 이 문서를 우선한다. 기존 화면 전체를 한 번에 바꾸라는 뜻은 아니다.

## 작업 시작과 검수

- 코드를 바꾸기 전 `AGENTS.md`, 이 문서, 수정할 실제 화면·토큰·공용 컴포넌트를 읽는다. 기억이나 스크린샷만으로 기존 값을 추측하지 않는다.
- 변경 전 현재 UI를 캡처하거나 렌더링해 상태를 확인한다. 변경 후 휴대폰 360px 및 넓은 화면에서 같은 화면을 다시 비교한다. 화면을 못 열었으면 시각 검수를 완료했다고 말하지 않는다.
- PR 설명에 화면별 탭/폰트/색/글래스/버튼/지도 아이콘 점검 결과와 스크린샷 또는 미확인 사유를 적는다. 실제 실행·검증 범위만 보고한다.

## 1. 상단 탭과 글꼴

- 화면 상단의 **탭 내비게이션을 새로 설계하거나 수정할 때**, 홈의 DESK · CHART · PROGRAMS · FLOW를 그리는 `SoriStageFolderTabs`(`lib/features/visit/sori_stage_folder_tabs.dart`)의 배치와 선택 표현을 기준으로 삼는다. 라벨은 해당 화면의 기능명으로 바꾸되 48dp 레일, 한 줄 텍스트, 좌우 12dp 바깥 여백, 폭 배분, 선택된 탭의 짙은 텍스트와 얇은 밑줄을 유지한다. 모든 화면에 DESK 등의 라벨 자체를 복사하지 않는다.
- 글꼴은 홈의 `Theme` 및 `HomeVisualTokens`를 확인하여 동일한 서체 계열·굵기 위계·행간을 사용한다. 탭은 실제 홈 소스의 선택 15/w800, 비선택 15/w600을 우선한다. 다른 화면의 기존 글꼴을 추측으로 덮어쓰지 않는다. 한글 말줄임과 글자 확대를 확인한다.
- 카드 정보는 이름 → 핵심 수치/상태 → 보조 출처 순서로 읽힌다. 한 카드에 모든 원본 데이터 필드를 나열하지 않는다.

## 2. 색 사용

| 역할 | 기준 | 사용 예 |
|---|---|---|
| 바탕·일반 표면 | 홈의 밝은 캔버스, 흰 카드, 차콜 글자, 연회색 보조 정보 | 화면 대부분 |
| 선택·활성 | 차콜 텍스트/테두리/밑줄 또는 지도 고유 강조색 | 탭, 칩, 선택 업소 |
| 양호/달성 | 선명한 초록 + 텍스트/아이콘 | 목표 달성률, 개선 |
| 주의/대기 | 선명한 노랑 + 텍스트/아이콘 | 기준에 가까움, 확인 필요 |
| 위험/악화 | 선명한 빨강 + 텍스트/아이콘 | 목표 미달, 악화 |
| 정보·위치 | 지도 계열 파랑 | 현재 위치, 검색, 업소 정보 |

**브랜드 보라색(`SoriTokens.brand`, `#8B5CF6`)은 기본 사용 금지.** 새 화면의 배경, 큰 버튼, 탭, 칩, 차트, 카드, 업소 마커를 보라색으로 자동 채우지 않는다. 기존 도메인에서 의미가 정해진 자산 또는 제품 소유자가 특정 요소에 명시적으로 요청한 경우에만 제한적으로 사용하고 그 이유를 PR에 쓴다. 공용 토큰에 보라가 있다는 사실은 사용 허가가 아니다.

빨강·노랑·초록은 통계와 퍼센트를 판단하게 하는 의미색이다. **지표별 목표값과 좋은 방향을 먼저 정의**한 뒤 적용한다. 상승이 언제나 양호한 것은 아니다(예: 비용·경쟁 점포 수). 임계값이 정의되지 않았으면 수치를 중립색으로 표시하고 임의로 좋음/나쁨을 판정하지 않는다. 색 외에 수치, 단위, 텍스트와 아이콘을 함께 제공한다. 이용 불가 값을 0%로 만들지 않는다.

## 3. 우리지역 ↔ 상권분석 지도

- 상권분석은 우리지역의 **밝은 지도, 업종 아이콘, 샵 마커 형태와 색 분류, 군집, 선택 표현, 검색·반경·업종 칩, 지도 제스처**를 승계한다. 출발점은 `lib/views/community/region_nearby_map_section.dart`와 `region_map_bloom.dart`의 실제 구현이다. 별도 지도 테마·전역 보라색 업소 마커·새 업종 아이콘 세트를 만들지 않는다.
- 두 화면의 차이는 **정보 계층**이다. 우리지역은 주변 업소 발견과 이동, 상권분석은 반경 내 분포·지표·근거·기준시점을 시각화한다. 상권분석의 분석 오버레이와 카드만 추가하고, 업소 자체를 표시하는 아이콘 언어는 공유한다.
- 공개 업소 데이터와 개별 매출 추정, 통계 기준월, 조회 시점을 혼동하지 않는다. 비어 있는 값은 미제공으로 표기한다. 지도 타일 위의 통계가 너무 많으면 요약 카드나 상세로 옮긴다.

## 4. 글래스와 블러

- 글래스는 하단 플로팅 내비게이션, 지도 도구, 짧게 뜬 검색·필터 패널, 지도 위 선택 카드처럼 **떠 있는 층**에만 사용한다. 지도와 글자를 읽을 수 있는 밝은 반투명 표면, 미세한 경계선, 약한 그림자를 기준으로 한다.
- 지도 위 패널에 실제 블러가 필요한 경우 해당 패널 범위만 `BackdropFilter`와 클립을 적용한다. 수치가 정해지지 않은 블러를 임의로 크게 올리지 않는다. 가독성이 떨어지면 불투명도를 높이고 블러를 줄인다. 긴 목록·차트·폼·화면 전체를 글래스로 덮지 않는다.
- 기존 투명 카드가 블러를 쓰지 않는다면 이를 실제 글래스 블러라고 보고하지 않는다. 스크롤·지도 이동 시 프레임과 글자 대비를 확인한다.
- **2026-09-26 개정 (제품 소유자 승인):** No-blur 글래스 룩(반투명 채움 + 헤어라인 + 하이라이트 + 그림자)은 컨트롤·버튼·칩에 앱 전역으로 허용한다. 실제 블러(`BackdropFilter`/블러 사본)는 떠 있는 층과 사진·지도 위 컨트롤에만, 화면당 1–3개, 목록 행에는 절대 쓰지 않는다. (No-blur glass look (translucent fill + hairline + highlight + shadow) is allowed on controls/buttons/chips globally; real blur (BackdropFilter/blurred copy) stays limited to floating layers and controls over photos/maps, max 1–3 per screen, never in list rows.) 기본 바탕은 웜 화이트 `SoriTokens.canvas`(#FBF9F6), 카드·시트·다이얼로그·입력칸은 흰색, 흰 카드 안의 묶음 채움은 `SoriTokens.fillMuted`. 토큰은 `lib/theme/sori_glass_theme.dart`.

## 5. 버튼과 간격

- 행동이 중요한 정도만큼만 버튼을 키운다. 작은 지도 카드와 업소명 버튼은 **시각적으로 조밀하게**: 텍스트 한 줄, 내용 중심 높이, 짧은 상하 패딩. `Spacer`, `Expanded`, 고정 높이, 기본 `ButtonStyle`의 최소 크기가 이름 위아래에 빈 공간을 만드는지 먼저 확인한다.
- 시각적 높이와 터치 영역을 구분한다. 터치 가능한 전체 영역은 접근 가능한 크기를 확보하되, 흰 배경의 큰 빈 버튼처럼 보이지 않도록 한다. 목록/검색/선택 카드에서 같은 업소의 간격 밀도가 일치해야 한다.
- 특별한 근거가 없다면 얇은 보조 동작을 대형 filled CTA로 바꾸지 않는다. 탭·칩·네이버 열기 등의 키와 콜백은 스타일 수정 시 그대로 유지한다.
- **우선 교정 대상:** 우리지역 지도 내 업소명 카드(`_ShopDiscoverRow`)의 상하 공간. 수정 전후 카드 전체 높이와 업소명 위/아래 간격을 360px 캡처에서 비교한다. 글자 확대, 긴 상호, 두 줄 정보, 선택 후 하단 내비게이션과의 겹침을 확인한다.
