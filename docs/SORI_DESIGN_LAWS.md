# SORI 디자인 법칙 (기존 문서 안내)

**2026-09-24 업데이트:** 제품 소유자가 지정한 현행 UI 기준은 [SORI 시각 디자인 기준](SORI_VISUAL_STANDARD.md)이다. UI를 만들거나 고치기 전에 현행 기준과 실제 홈·우리지역 화면 소스를 먼저 읽는다. 이 문서의 이전 브랜드 보라색 기본 사용, 화면당 filled CTA 정확히 하나, 지도에 상권 지표 전면 금지 규칙은 폐기했다.

## 계속 지킬 원칙

1. 첫 화면에서 현재 맥락과 다음 행동을 바로 찾게 한다. 카드에 원본 데이터를 모두 펼쳐 놓지 않는다.
2. 색 외에 수치·단위·문구·아이콘으로 상태를 설명한다. 값이 없으면 상태나 0을 만들어 넣지 않는다.
3. 글래스는 읽을 수 있는 떠 있는 도구에 제한한다. 목록과 긴 폼을 겹겹이 반투명하게 만들지 않는다.
4. 지도 마커 선택, 목록 선택, 시트 이동, 위치 재검색은 기존 동작을 보존한다. 시트 드래그에 타일·마커·API를 매번 다시 그리지 않는다.
5. 주요 터치 영역의 접근 가능한 크기를 유지하고 아이콘만 있는 버튼에는 한국어 의미 이름을 붙인다. 버튼의 **보이는** 크기와 콘텐츠 여백은 현행 기준에 맞춰 조밀하게 구성한다.
6. 미동의 사진, 결제 완료, 실제 영업 상태, 개별 업소 매출 등 데이터 계약에 없는 사실을 UI가 만들어 표시하지 않는다.
7. 빈 상태는 다음 행동을 안내한다. 에러 코드 자체를 일반 사용자 문구로 노출하지 않는다.

이전 디자인 규칙을 복사한 Cursor 프롬프트·코드 주석보다 `docs/SORI_VISUAL_STANDARD.md`의 제품 소유자 지시가 우선한다.
