# SORI 디자인 절대 법칙

**Status:** Locked · Cursor Agent 디자인 계약 · UI 구현 전 필독  
**작성:** 2026-09-11 · PO

아래는 Cursor Agent가 SORI에서 UI를 만들거나 수정할 때 따라야 하는 **디자인 판단의 헌법**이다. 기능이 동작하더라도 이 규칙을 위반하면 디자인은 불합격으로 간주한다.

SORI의 목표는 “예쁜 카드 모음”이 아니다. **1인 샵 원장이 바쁜 순간에도 상태를 즉시 읽고, 기록을 남기고, 고객 관계와 경영 판단으로 이어가는 감각적인 운영 OS**를 만드는 것이다.

---

## 0. 디자인 선언

> **SORI는 무채색 배경 위에서 기능과 상태가 색으로 살아나는, 글래스 물성을 가진 1인 샵 운영 OS다.**
>
> 배경은 조용하다. 정보는 계층을 가진다. 행동은 단 하나가 선명하다.  
> 색은 의미를 가진다. 터치는 즉각 반응한다. 지도는 도시의 생기를 보여준다. 기록은 부담 없이 완결된다.

### Cursor 최우선 원칙

```text
기능을 화면에 “올려놓지” 말 것.
사용자가 무엇을 먼저 보고, 무엇을 누르고, 누른 뒤 무엇이 바뀌는지 설계할 것.
```

---

## 제1칙. 한 화면에는 한 가지 목적만 둔다

| 화면 | 유일한 목적 | 넣어도 되는 것 | 넣으면 안 되는 것 |
|---|---|---|---|
| 홈 | 시술 전·중 5초 glance | 주간 스트립, 오늘 일정, note 1줄 | KPI, 매출, CRUD, 타이머 복제 |
| 사장 책상 오늘 | 사후 정리·후속 업무 확인 | 업무 큐, 경영 peek, 상세 일정 | 시술 실행 제어, 피드, 공개 쇼룸 |
| 고객 상세 | 고객 관계의 누적 맥락 확인 | 다음 일정, 고객 메모, Visit 타임라인 | KPI 6개, SOAP 원문 전개 |
| 방문 기록 | 한 Visit 기록 완결 | 요약, 선택 사진, 다음 관리 | 결제 추정, 공개 홍보 강제 |
| 경영 | 결과·원인·다음 판단 | 시간당 수익, A/B 돈 분리, 차트 | 업무 큐처럼 보이는 인사이트 |
| 공개 프로필 | 신뢰·사례·문의/예약 전환 | 대표 B/A, 후기, CTA | 매출, 고객 기록, 내부 메모 |
| 우리지역 지도 | 지역 콘텐츠 발견 | 글·세미나·상권 탐색, marker, sheet | 고객/Visit, 매출 비교, 지도 위 피드 |

금지: “기능이 있으니까 보인다”로 넣지 않는다. 목적을 방해하면 다른 surface로 보낸다.

---

## 제2칙. 3초 안에 위계가 보여야 한다

```text
1. 지금 가장 중요한 것
2. 내가 보고 있는 맥락
3. 다음 행동
```

| 시각 계층 | 역할 | 허용 수 |
|---|---|---:|
| Level 1 | 가장 중요한 행동 또는 상태 | 화면당 1개 |
| Level 2 | 현재 맥락/보조 행동 | 최대 2~3개 |
| Level 3 | 상세 정보/탐색 | 스크롤·확장 뒤 |
| Level 4 | 설정·저빈도 기능 | 더보기·상세 화면 |

**한 화면의 filled primary CTA는 정확히 1개.**

---

## 제3칙. 색은 장식이 아니라 언어다

| 색 | 고정 의미 | 허용 | 금지 |
|---|---|---|---|
| **Purple** | 브랜드·주요 행동·자산·선택 | primary CTA, B/A, AI, 선택 tab, **커뮤니티 글 marker** | 모든 제목/아이콘 |
| **Blue** | 위치·탐색·정보 | GPS, 지도, 정보 보기 | 완료, 삭제 |
| **Green** | 완료·정상·성공 | 기록 완료, 저장 성공 | 기본 CTA 장식 |
| **Yellow** | 확인 필요·보류 | 기록 미완료, 주소 확인 | 보통 버튼·성공 |
| **Red/Coral** | 파괴·오류·시간 민감 | 삭제, 공개 철회, 실패, **세미나 marker** | 일반 알림 |
| **Gray/White** | 구조·보조·중립 | 표면, secondary | 상태의 유일한 표현 |

색 예산: filled primary 1 · 동시 semantic 강조 ≤2 · 지도 marker 의미색 2 · 선택=기존색+ring.  
**색만으로 상태 전달 금지 → icon + label + color.**

---

## 제4칙. 글래스는 떠 있는 도구에만 쓴다

허용: FloatingPillNav, 지도 GPS/저장함, Peek/Half 상단, 선택 floating control.  
금지: 모든 list row, 타임라인 전체, 방문 입력 폼, 긴 리포트, 삭제 modal, 카드 중첩 glass.

---

## 제5칙. 터치는 짧고 단단하게

| 상호작용 | Press | Release |
|---|---|---|
| 글래스 버튼 | scale 0.97 | 160~220ms ease-out |
| Primary CTA | 0.97 + 밝기 | 상태 갱신 |
| 북마크 | outline→filled + 0.92~0.95 | 160~220ms |
| 지도 marker | 1.05~1.10 + ring | Peek 동기화 |
| GPS | blue tint + pulse 1회 | 이동 후 안정 |

금지 bounce: map pan, sheet drag, list scroll, tile/network loading.

---

## 제6절. 상태는 진실만 보여준다

스키마/계약에 없는 결제 완료·노쇼·자동 방문완료·GPS 이력·미동의 B/A를 UI가 발명하지 않는다.

---

## 제7절. 점진적 공개

지도: marker Peek → Half 목록 → 콘텐츠 상세 route.  
처음부터 긴 피드를 sheet에 억지로 넣지 않는다.

---

## 제8절. 지도 = SORI Local Bloom

예쁜 컬러 도시 캔버스. 글=Purple, 세미나=Coral, 선택=ring.  
고객/Visit/내부 B-A/매출/경쟁/무지개 marker/그라데이션 cluster/spiderfy/가짜 서울/전면 glass overlay 금지.

위계: 선택 > 글/세미나 marker > cluster > preview sheet > GPS/저장함 > 베이스맵.

---

## 제9절. 빈 상태도 기능이다

주소 없음 → `우리 지역의 글을 보려면 샵 주소를 등록해 주세요.` + [주소 입력]  
저장함 빈 → `저장한 글과 세미나가 여기에 모여요.`  
상권 실패 → `이 지역의 상권 정보를 불러오지 못했어요.` + [다시 시도]

금지: 큰 일러스트, “데이터가 없습니다”, 오류 코드.

---

## 제10절. 카피는 행동과 결과

금지: Analytics, Dashboard, Insights, GPS 오류, 권한이 거부되었습니다, 지도 로딩 실패, 인기/추정 매출.

---

## 제11절. 접근성

주요 hit ≥48×48dp. icon-only는 한국어 semantics/tooltip. 글/세미나는 색+glyph+시트 유형 라벨.

---

## 제12절. 성능은 디자인이다

Sheet drag ≠ 타일/marker/API. Filter ≠ 중심 리셋. Bookmark ≠ 전체 marker rebuild.

---

## 제13절. 구현 전 자가 검수 (10문)

1. 이 화면의 단 하나의 목적은?  
2. 3초 안에 가장 중요한 행동을 찾는가?  
3. filled primary CTA가 정확히 하나인가?  
4. 이 색은 고정 semantic인가?  
5. 글래스가 떠 있는 도구에만 쓰였는가?  
6. 데이터 계약에 없는 상태를 발명하지 않았는가?  
7. 점진적으로 열었는가?  
8. 빈 상태가 다음 행동을 주는가?  
9. hit·대비·한국어 semantics가 충족되는가?  
10. 이 모션/blur/color가 이해를 높이는가, 장식인가?

하나라도 아니오 → 구현 중단, 설계 재제안.
