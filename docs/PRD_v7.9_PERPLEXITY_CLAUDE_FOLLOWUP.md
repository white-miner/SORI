## C1. “시술 후 기록 미완료” 운영 정의 (살롱/뷰티 SaaS)

목표: 업무 큐 1순위 트리거를 **측정 가능한 체크리스트**로.

| 물을 것 | 원하는 산출 |
|---------|-------------|
| Square / Vagaro / GlossGenius 등에서 “체크아웃 미완료·기록 미완료·노트 미작성”을 무엇으로 보는가 | 표: 조건 필드 후보 · AND/OR · 예외(노쇼·상담만) |
| 사진 필수 vs 선택인 업종 차이 | 뷰티·네일·타투 한 줄씩 |
| “부분 완료(초안)”를 큐에 넣을지 말지 | 권고 1안 |

소리 가정(참고만, 검증 대상): Visit≈차트 row · 방문확인 플래그 · 전후 사진 URL · 본문/요약 텍스트가 흩어져 있을 수 있음.

**산출:** `기록 미완료` / `부분 완료` / `완료` 정의표 + PO가 Yes/No로 고를 옵션 2개.

## C2. 일정 메모 UI 패턴 (모바일)

전제: 홈=읽기 glance · 메모 편집은 마이 상세. 무소속 스크래치 금지.

| 물을 것 | 원하는 산출 |
|---------|-------------|
| 예약/일정에 붙는 메모를 **바텀시트 / 인라인 / 탭 / 전체화면** 중 어디에 두는지 | 사례 3 + 장단 |
| 홈에서 “메모 미리보기(아이콘·1줄)”만 두고 탭 시 마이로 보내는 패턴 | 채택 여부 권고 |
| 메모 히스토리(과거 일정에도 유지) UX | 유지 vs 세션 종료 후 접기 |

**산출:** SORI 권고 1안(플로우 4단계) + 금지 1줄.

## C3. 프로필 “대표 사례” 개수

전제: 커뮤니티 공개 B/A 중 **명시 선택**만 프로필 미러 · 철회 시 양면 숨김.

| 물을 것 | 원하는 산출 |
|---------|-------------|
| 뷰티/포트폴리오 앱의 featured/대표 전후 개수 | 1 / 3 / 5 / 무제한 중 관행 |
| 대표 해제만으로 커뮤니티 공개는 유지하는가 | Yes/No 권고 |
| 대표 선택 UI(체크 vs 별 vs 드래그 정렬) | 모바일 권고 1안 |

**산출:** 기본 **최대 N개** + 커뮤니티 공개와 프로필 대표의 독립성 규칙 3줄.

## C4. 알림 → 백오피스 일정 딥링크 (홈 우회)

전제: 알림이 홈 탭을 열면 안 됨 · 마이 오늘/일정 상세로.

| 물을 것 | 원하는 산출 |
|---------|-------------|
| 푸시/인앱 알림이 **특정 일정·고객**으로 직행하는 앱 사례 | 경로 패턴(탭 전환 vs 모달 vs 풀스크린) |
| 대상 삭제/권한 없을 때 폴백 | “목록으로” vs “오늘 큐로” |
| “홈 금지”를 기술적으로 지키는 표현 | 제품 문장 1줄 |

**산출:** SORI deeplink 계약 초안 1표 (경로 · 폴백 · 금지).

## C5. 실행 큐 vs 인사이트 알림 분리

전제: 마이 오늘 큐=실행 · 경영 “지금 확인할 일”=인지/분석.

| 물을 것 | 원하는 산출 |
|---------|-------------|
| GlossGenius Needs action vs 분석 카드 / 토스·POS의 운영 알림 vs 리포트 | 분리 표 |
| 마이 홈(오늘)에 **위험 peek 1줄**(예: 목표 대비 낮음)을 두는 것이 이중 OS인지 | 권고: 두기/말기 + 조건 |
| peek 클릭 시 분석 화면으로만 보내고 큐와 섞지 않는 규칙 | 3줄 |

**산출:** “큐에 넣으면 안 되는 인사이트” 목록 + 마이 오늘 peek 허용 범위.
